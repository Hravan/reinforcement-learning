Scope: chapter 2, k-armed bandits.

classDiagram
    class Action {
        +float value
        +float std
        +bool stationary
        +perform() float
        +gaussian(mean, std, **kwargs)$ Action
    }

    class Experience {
        +list~int~ action_history
        +float sum_rewards
        +update(action_index, reward)
        +n_selected(action_index) int
        +last_action int
        +n_selected_last_action() int
        +mean_reward float
        +len() int
    }

    class Agent {
        +tuple~Action~ actions
        +list~float~ reward_estimates
        +Experience experience
        +ActionSelectionMethod action_selection_method
        +StepSizeMethod step_size_method
        +act()
        +optimal_action int
        +mean_reward float
        +n_selected(action_index) int
        +n_choices int
    }

    class EpsilonGreedyAgent {
        +__init__(*actions, epsilon, **kwargs)
    }

    class ActionSelectionMethod {
        <<interface, duck-typed>>
        +__call__(agent) int
        +update(action_index, reward)
    }

    class StepSizeMethod {
        <<interface, duck-typed>>
        +__call__(agent) float
    }

    ConstantStepSize ..|> StepSizeMethod

Notes:

- ActionSelectionMethod and StepSizeMethod are duck-typed protocols, not
  real Python base classes: any callable with the shown signature qualifies.
- Agent holds action_selection_method and step_size_method as plain
  attributes and calls them as self.action_selection_method(self) /
  self.step_size_method(self) from act().
- SampleAverageStepSize is the default step_size_method (1 / n times this
  action was chosen).
- EpsilonGreedyAgent is a thin Agent subclass that wires up EpsilonGreedy
  as the action-selection strategy.
